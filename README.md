## ✨ Fitur-Fitur Utama

- 🏰 **Realm Command Center**: Dashboard interaktif dengan status HUD ksatria, XP gauge, energi fokus, dan streak harian.
- 📜 **Papan Quest & Task Manager**: Manajemen to-do list dengan 3 kategori (*Legendary, Daily, Side*), subtasks checklist, dan estimasi waktu.
- ⏱️ **Duel Fokus (Pomodoro 25m)**: Timer konsentrasi bertema pertempuran dengan sound effects retro 8-bit.
- 👑 **Raid Boss Encounter**: Pertarungan World Boss dengan bar HP dinamis, kelemahan elemen, dan reward kemenangan melimpah.
- 🛡️ **Armory & Toko Pandai Besi**: Inventaris perlengkapan (*Weapon, Shield, Armor, Pet, Potion*) dan bonus atribut pasif.
- 🎁 **Vault Apresiasi Diri (Self-Reward)**: Kunci target hadiah nyata di dunia nyata hingga target XP tercapai.
- 🏆 **Aula Trofi & Prestise**: Sistem pencapaian prestasi berhadiah Permata (*Gems*).
- 📊 **Kalender & Analitik Produktivitas**: Heatmap hari aktif, grafik tren XP, dan grafik menit fokus.
- 📱 **100% Responsif Desktop & Mobile**: Dilengkapi *Bottom Navigation Bar* dan *PWA Ready*.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, TailwindCSS v4, Recharts, Canvas Confetti, Web Audio Synthesizer.
- **Backend**: Node.js, Express, TypeScript (tsx).
- **Database**: In-Memory + JSON-backed File Storage (Local) & PostgreSQL Prisma Schema (Production Ready).

## 🚀 Memulai Aplikasi Secara Lokal

### 1. Kloning Repositori
```bash
git clone https://github.com/gyonmd-tech/Warrior-Quest.git
cd Warrior-Quest
```

### 2. Instal Dependensi
```bash
npm install
```

### 3. Jalankan Server Pengembangan
```bash
# Menjalankan Frontend (Vite)
npm run dev

# Menjalankan Backend API (Express)
npm run server
```

Buka `http://localhost:3000` atau `http://localhost:3001` di browser Anda.

---

## 📦 Build untuk Produksi
```bash
npm run build
npm start
```
